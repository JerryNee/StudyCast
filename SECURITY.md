# Security Policy

StudyCast receives local-network AirPlay streams and launches bundled helper binaries. Please report security issues privately.

## Supported Versions

Only the latest beta release is supported for security fixes.

## Reporting a Vulnerability

Open a private security advisory on GitHub, or contact the repository owner privately if advisories are unavailable.

Please include:

- StudyCast version and macOS version.
- Whether the issue affects the source build, release DMG, or both.
- Steps to reproduce.
- Any logs from the affected station's `.uxplay.log` file.

Do not publish exploit details until a fix or mitigation is available.
